点「添加引脚」→ 鼠标移到任意元件轮廓上（出现蓝色落点）→ 点一下生成引脚 → 从引脚拖拽连线 → 再进模式悬停引脚点「×」删除；Esc 退出。 ready

① 你原有的代码（完全不动）

const graph = new Graph({
  container: '#graph',
  connecting: { allowBlank: false },
})
graph.addNode({
  id: 'a', x: 80, y: 90, width: 130, height: 60,
  attrs: { body: { fill: '#fff', stroke: '#5F95FF' },
           label: { text: '设备 A' } },
  /* 你自己的端口定义也照旧 */
  ports: { groups: { pin: { position: 'absolute' } }, items: [] },
})
graph.addNode({ id: 'b', /* ...设备 B... */ })

② 新增的接入代码（就这几行）

import { PortEditor } from 'x6-plugin-port-editor'

const portEditor = new PortEditor()
graph.use(portEditor)

document.getElementById('btn-add-pin')
  .addEventListener('click', () => {
    portEditor.isAdding()
      ? portEditor.stopAdding()
      : portEditor.startAdding()
  })

其余全自动：缺 pin 端口组时插件补一份默认定义（白点 + magnet）；已有定义优先使用。 插件对 @antv/x6 只有类型引用，产物零运行时依赖 —— 你项目里的那份 X6 就是它用的那份。
