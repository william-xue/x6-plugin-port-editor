要端子就得…不接插件（X6 原生）接上插件
端子从哪来 在元件定义里预先声明 ports.items，或运行时 node.addPort({ args: { x, y } }) —— 坐标由你算 点一下轮廓就地生成，坐标由 CTM 链换算写在 ports.items[].args
异形元件（圆 / 多边形 / 自定义 path） 自己按几何算：圆心半径、顶点表、贝塞尔采样……；元件 resize / rotate 之后还要重算 投影到元件真实 SVG 轮廓，缩放 / 平移 / 旋转都不用特判
鼠标移到轮廓上 没有反馈。X6 核心从不绑定原生 mousemove，node:mousemove 只在拖拽过程中触发 出现落点预览（就是将要生成的端子位置）
删端子 自己做 UI（右键菜单 / 选中后按 Delete / 侧栏列表） 悬停引脚 → 点「×」；连在它上面的线一并删掉，且是一步撤销
从端子拉线 X6 原生能力：magnet: true 的端子本来就能起线 一样（插件不改这条语义，进添加模式时也照常放行）

左边两个「手写坐标」按钮演示的就是真实的手工成本：「估一个」把端子放在元件框的角上（离真实轮廓有一段距离，下面那行数字会告诉你多远）； 「算准了」把圆心半径算出来放对位置 —— 能做到，但每次换形状、每次 resize 都得重来一遍。右边你只需要点一下轮廓。
