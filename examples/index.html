x6-plugin-port-editor · 例子

两个例子由浅入深，都基于 dist/index.umd.js，无需打包器即可打开。 完整说明（接入清单 / 共存 / 已知坑 / 实现原理）见 docs/INTEGRATION.md 与 examples/README.md。

例 1 · 最小接入 已经有一个跑着的 X6 图，怎么把插件接上去：页面左侧列出「你原有的代码」，右侧是「新增的 8 行」， 代码与页面一一对应。含：进入添加模式、点轮廓生成引脚、从引脚拉线、悬停删除。 例 2 · 电力组件场景（完整） 自定义元件形状（CT / 主变 / 断路器，Graph.registerNode）、 自己命名的端子组与端子样式、调色板拖元件与拖端子、 与 Selection / History 共存（端子增删可撤销）、导出 / 导入整图。

本地怎么跑

cd x6-plugin-port-editor
npm install          # 会自动构建 dist（prepare 脚本）
npm run demo         # 起静态服务
# 然后打开：
#   http://127.0.0.1:8732/examples/index.html
#   http://127.0.0.1:8732/examples/01-basic/index.html
#   http://127.0.0.1:8732/examples/02-power-editor/index.html

例子里用到的能力都可以照抄到你自己的项目：换元件形状改 Graph.registerNode 的定义， 换端子外观改 TERMINAL_GROUP，端子组名通过 new PortEditor({ group: '你的组名' }) 指定。
